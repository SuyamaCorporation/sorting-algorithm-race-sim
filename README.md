# Sorting Algorithm Race Visualization Simulator
Side-by-side animated race between Bubble Sort, Insertion Sort, Merge Sort, and Quick Sort on the same shuffled array.
## Features
- Four synchronized bar charts all starting from the same shuffled array
- Bars color-coded: blue (default), yellow (comparing), green (sorted)
- Speed slider from 1 to 100 steps per second
- Comparison and swap counters below each chart
- First algorithm to finish receives a star badge
- Array size slider from 30 to 60 elements
## Tech
Static SPA · Tailwind CDN · Canvas/localStorage
